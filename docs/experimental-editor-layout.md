# 实验性字幕工作区

入口：`/editor?project=<project_id>&layout=experimental`。主工具栏保持原位置，视频和工具在左上，多行波形在左下，Cue 列表占右侧整列。

波形提供每行时长、振幅设置、点击定位、双击播放/暂停、边缘调时、整体移动，以及右键或 N 创建。Ctrl 拖拽可指定创建范围。右键空隙直接创建主字幕 Cue，并在 Cue 编辑区打开整句编辑框，无弹窗；新字幕占位文字全选，点击外部保存，支持撤销。叠加字幕创建入口已移除。

已有叠加字幕保留兼容，使用现有纯文本 Cue 数据结构，`mapping.subtitle_track = "overlay"`，没有显示词元和源词元。Cue 编辑区以紫灰色独立文本块显示，不显示词级修订标记。保存、撤销、隐藏/恢复、时间修改和现有 SRT/ASS 导出沿用项目版本链。

MAWE v1.8.0-beta.1 参考核对：`web/editor/media/waveform/canvas.js`、多行渲染、字幕拖动模块、帮助分区和当前字幕编辑模块。这里在 Substar 的秒级时间与版本操作接口上独立实现所需交互，没有直接复制 MAWE 的 AGPL 源码。

当前字幕编辑核对：MAWE 的 `commitCuePanelEdit` 更新整句 `seg.text`，保留 `seg.items`，经 `remapPanelItems` 映射时间。仅改文字通常保留原来的时间数值，但不会同步修改 items 中的词级文字；修改起止时间会按旧/新范围比例缩放、取整并限制到段内。因此不会直接清空词级记录，但不能保证改写后的文字仍与原词级记录对应。Substar 的主字幕继续使用原有词元机制，新增叠加字幕明确没有词级时间。

验证：`tests/test_overlay_cues.py`、`tests/editor_multiline_timeline.test.js`，以及独立项目副本中的添加、编辑、刷新和主字幕词元不变检查。

视觉参数：波形每行 180 像素；单语字幕条 48 像素，双语每条 40 像素，文字 14 像素。字幕横向长度仍严格对应时间范围。窗口峰值请求 4096 点，以物理像素列绘制最大峰值，不连接相邻峰值形成斜面；默认振幅为 1.3 倍，可在齿轮中调整。

行尾紫点双击进入整行编辑，失焦保存，Esc 取消。使用现有 merge/replace 操作与版本链：多词改写后合并为一个显示词块，源词与时间记录不变，整条起止时间不变；撤销恢复原显示词结构。已在独立项目副本验证失焦保存和撤销，原项目未写入测试文字。

单词双击编辑使用可自动换行的输入框，最小宽度 64px，随文字扩展至当前内容区宽度，并自动增高；左右内边距分别为 8px 与 12px，缩减短词右侧空白。单词替换继续沿用原有词元时间。

波形标题旁提供「基础 / 多行」切换，默认多行。基础模式将同一套波形与字幕绘制为连续横向时间轴，完整媒体可左右滚动；使用滚轮横移，修饰键滚轮仍可缩放。两种模式共用字幕选择、定位、调时及空隙创建操作。工具区与波形模块背景加深。

任务信息右侧布局菜单仅保留标准、经典、大屏。标准保持视频与工具并排、左下波形、右侧 Cue；经典对应原编辑器：左上工具、中上字幕、右上预览，下方波形横贯全部三列；大屏对应参考图：左侧大预览，右上工具、右下 Cue，波形横贯底部。分界按布局调整，标准 Cue 只调宽；经典上下分界共同调整工具/字幕/预览与全宽波形高度；大屏上部分界调整预览/右侧整体宽度，右侧工具/Cue 高度与全宽底部波形高度可调。范围有上下限，支持拖动与方向键微调。布局及各布局尺寸保存在本机浏览器，顶部编辑状态提示隐藏。


## 编辑状态岛与说话人菜单

实验性布局保留原来的状态岛结构：AI 任务进度在上，保存状态和撤销、恢复、暂存、重置、刷新在下。仅优化间距、文字层级、任务状态过渡与按钮动效；尊重系统减少动态效果设置。说话人设置改为顶部下拉表单，保留四种色标、名称保存与取消。原布局仍使用原来的弹窗。实验性字幕列表标题改为「字幕」。

无 AI 任务和错误时，状态岛按五个操作按钮的实际宽度收紧，去掉保存状态说明文字；任务、错误或暂存名称输入出现时恢复展开。实验性顶部「任务信息」改为「信息」，项目菜单去掉「打开原布局」。波形高度调节改用像素下限，最低保持约 180px 的完整绘图区（模块总高约 250px），呈现多行中的单行形态；基础模式在下限使用相同的波形中心与振幅。

AI 翻译点击执行后立即显示启动状态；状态岛宽高通过 240ms 过渡展开，活跃任务进度条带流动提示，减少动态效果设置下关闭动画。

展开任务卡片宽度收紧至 360px，移除「当前修改自动写入版本链」的可见文字与悬停说明，标题、进度、任务摘要和五个操作按钮紧凑排列；无内容的任务行不预留空白。

工具区宽度达到 400px 时，五个标签改为左对齐的紧凑横排，图标与文字并列，按钮不随模块宽度拉伸；窄工具区继续使用五列竖向图文按钮。使用容器查询，随边缘调节自动切换。

五个工具面板采用专门的横向布局（容器宽度至少 520px）：定位的三类导航并排；查找、替换各占一行，输入与操作在同一行；标点按上下行规则排列；吸附按向前/向后分组并列，操作置于右下；帮助按编辑、波形、变更说明分区并排。吸附参数在 760px 以上继续横排，较窄时在组内纵排。既有输入与按钮节点保留，窄栏维持原来的纵向排列。已验证五个宽栏面板与经典窄栏切换，无横向溢出。

字幕视图改为与波形模式一致的「光标 / 辅助点」分段胶囊，启动修订紧随胶囊右侧。「显示译文」改为带浅蓝复选框的「双语字幕」按钮。保留原有选择状态、禁用状态和显示开关逻辑，已验证双向切换。

### 工具栏与暂存版本（2026-10-04）
字幕视图胶囊紧跟字幕标题；字号调节合并为一个控件，双语字幕使用更深背景。项目改称选择项目，信息改称项目配置，导入移到导出左侧，布局改为工作区下拉选择。版本菜单从顶部移到灵动岛替代重置，只列出人工暂存快照并支持恢复整版。五个历史按钮等宽等高；从版本菜单跳转后清空撤销、恢复记录，持久化空记录使刷新后继续从该状态开始。
验证：三个布局及版本菜单显示；17 项编辑操作测试、2 项历史测试通过；模拟版本跳转验证请求和持久化记录的撤销、恢复列表为空。

暂存命名状态：灵动岛向左横向展开至最多 560px，受字幕面板宽度约束。名称输入、取消、确定与历史按钮横向排列；动作按钮始终保持 56px 宽、34px 高，不随岛宽度拉伸。上方 AI 任务区域同步填满展开后的宽度。取消后恢复紧凑状态。
