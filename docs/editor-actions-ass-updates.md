# 编辑动作、ASS 和应用内更新

## 编辑与版本历史

- “合并”会立即打开合并后的文字输入框，确认时将合并和文字修改作为一个动作提交；取消输入也取消合并。
- 工具栏最右侧“拆分”开启词元内部右键切分，两段各分配原时长的一半。点击其他位置退出。使用现有的 subdivided 时间来源标记，不修改项目格式。
- 编辑队列按用户动作提交，避免把短时间内的独立动作混成一次撤销。显式指定相同 `user_action_id` 的子操作可以一起提交。
- “暂存”左侧显示名称输入框，按钮变为“取消”，右侧显示“确定”。命名节点显示在“版本”菜单中，不受最近 30 个普通版本的显示限制影响；暂存保留项目的完成状态。
- 在“版本”中选择旧节点，可以恢复整版，或只恢复所选字幕的文字、时间、译文。没有词元选择时使用当前字幕。选择性恢复追加新修订，不删除后续历史；原文改变时将已有译文标为需要检查。若词元结构不再对应，拒绝文字恢复并提示使用整版恢复。
- 自动吸附保持先向前调整起点，再向后处理间隙的顺序。大小写改进只涉及校准提示词。

## ASS 菜单与服务

视频预览右上角的 ASS 菜单沿用任务信息菜单样式，是可拖动、带独立关闭按钮的悬浮面板。宽屏四列，窄屏两列。默认白色加粗上行、淡黄色加粗下行、黑色描边及半透明底色；参数按 1080 高度的参考画布保存，输出保留视频宽高比。

Cue 编号或卡片空白处单击单选，Shift 连选，Ctrl 增减选择。从原文区域起拖框选词元；从 Cue 编号、卡片边缘或行间空白起拖选择 Cue。两者均显示选择框，靠近列表上下边缘自动滚动；拖动对象由起点决定，跨过其他区域不切换。进入词元选择清除 Cue 多选，进入 Cue 选择清除词元选择；译文输入框保留原生文字选择。播放跟随不会清除 Cue 多选。打开 ASS 保留已有 Cue 选择并默认针对它们，亦可切换项目默认。

样式方案包含样式字典和有序字幕层；每层独立指定内容、样式、显示状态和逐词高亮。原文/译文是内容角色，与上行/下行位置分离。添加更多层可重复显示现有内容，不代表新增语言数据轨；层内换行仍属于同一层。现阶段没有任意 ASS 文件导入编辑或 Moy 全部动画选项。

普通编辑只应用修改过的层，保留所选字幕其他层的差异；载入完整方案、增删层则应用整个方案。只覆盖下行的 Cue，其上行继续继承项目默认。恢复项目默认会清除该 Cue 的覆盖。方案库支持载入、另存（同名更新）和删除；库的后续变化不会反向改变已应用的项目或历史。

配置存于既有 `changes[].metadata.ass`，不新增 Cue、词元或项目表字段。当前文档只保留一份有效样式配置；不同历史修订各自保留对应快照。相同方案用内容 ID 去重，Cue 仅引用方案 ID 和覆盖的层 ID。一次批量应用保存一次修订；撤销、重做、命名暂存、整版恢复均带回样式，选择性恢复新增“仅字幕样式”。

实时预览通过本地 SubtitlesOctopus/libass WASM 播放与导出相同的 ASS 文本，当前帧及烧录使用 FFmpeg/libass。Windows 已安装字体通过本地只读接口提供，字体文件不打包分发；同名字体缺失或两端 libass 版本差异仍可能影响排版。默认字体以及粗体实测共用系统字体。没有外部 CDN 或云端字幕传输。

方案结构参考 [Moy 的 ASS 样式模块](https://github.com/Moyf/moys-asr-workflow/blob/main/maw/ass_styles.py) 中样式、输出方案和引用分离的做法，未复制其 AGPL 源码。实际复用的是 [SubtitlesOctopus](https://github.com/libass/JavascriptSubtitlesOctopus) 的官方 `libass-wasm@4.1.0` 构建；来源及包校验信息见 `web/vendor/libass/PROVENANCE.json`，许可证和依赖版权声明随组件保留。

服务层样式支持字体、字号、颜色、当前词高亮色、描边、阴影、对齐、边距及淡入淡出。支持原文、译文和双语输出。逐词高亮要求原文与词级时间可对应；普通 SRT 和无法对应的投影文字不会伪造词级时间。

- `GET /api/ass/styles`：读取独立样式配置。
- `PUT /api/ass/styles`：保存 `{ "name": "样式名", "style": { "size": 54 } }`。
- `GET /api/ass/profiles`、`PUT/DELETE /api/ass/profiles/{name}`：可复用方案库；旧独立样式 API 保留兼容。
- `GET/POST /api/projects/{project_id}/ass/configuration`：读取有效配置或按所选 Cue、所选层提交一次修订，要求 `expected_revision_id`。
- `POST /api/projects/{project_id}/ass/export`：导出 ASS。
- `POST /api/projects/{project_id}/ass/render`：后台生成预览帧或烧录视频。
- `GET /api/ass/renders/{job_id}`：读取任务状态。
- `GET /api/ass/renders/{job_id}/file`：获取完成的输出。

导出和渲染请求示例：

```json
{
  "expected_revision_id": "当前修订 ID",
  "options": {
    "width": 1920,
    "height": 1080,
    "mode": "source",
    "word_highlight": true,
    "style": { "font": "Microsoft YaHei", "size": 54, "highlight": "#FFFF00" }
  },
  "preview_seconds": 12.5
}
```

上例为兼容旧独立样式 API。新菜单设置 `use_configuration: true`，使用当前修订的完整分层配置；未应用的草稿可传 `profile`、`cue_ids`（null 为项目默认）、`layer_ids`（null 为整个方案）临时预览/导出，不写入修订。渲染时省略 `preview_seconds` 或传 `null` 生成新 MP4；传时间生成 PNG。原媒体不会被覆盖。

文字转义按照 [libass 字符解析实现](https://github.com/libass/libass/blob/master/libass/ass_parse.c) 处理花括号；反斜杠后插入不可见 word joiner，避免原文中的 `\N` 等内容变成控制符，保留可见字符。

## 应用更新

入口为“设置 → 通用 → 应用更新”。检查 `CloudsOcean/substar-portable` 的最新正式 GitHub Release，匹配 `Substar-Windows-x64-vX.Y.Z.zip`。下载必须通过 GitHub 提供的 SHA-256、文件大小、包版本和路径检查。

自动安装仅支持正式 Windows 便携目录，源码工作区不会被替换。下载完成后保存设置并重启；有排队或运行中的后台任务时拒绝安装。启动器退出并释放文件后，由隐藏的 PowerShell 辅助进程备份、替换程序文件，再执行新版本导入检查。替换或导入检查失败时恢复备份，记录结果并重启旧版。此检查不能覆盖应用启动后的所有运行时故障。

更新包只允许程序文件，项目、密钥、设置、模型和更新备份保留在数据目录。发布方必须提供符合现有便携包布局且带 GitHub digest 的完整 ZIP；未在本次修改中发布新版本或升级现有安装。

## 验证

回归覆盖按动作提交、合并后一次撤销、选择性恢复与结构冲突、命名暂存、拆分时间、ASS 高亮与转义、更新包校验。真实 FFmpeg 完成预览帧和字幕烧录；隔离的 Windows 目录验证了替换成功与失败回退，并核对项目和模型文件未改变。浏览器测试覆盖编辑动作、命名输入、版本菜单和更新页。


### 选择与播放联动回归

单击 Cue 原文空白处仍选择并定位该 Cue；只有超过拖动阈值才接管框选并暂停跟随。鼠标按下时保留原生失焦，避免译文编辑挡住后续单击。显式跳转可定位列表；长列表延迟排版后重新校正位置，新的导航或手动滚动会取消旧校正。

浏览器验证覆盖译文焦点切换、词元/Cue 框选后跳转，以及真实长项目向前、向后跨页定位。147 项前端测试通过。
