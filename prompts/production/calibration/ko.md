# 원문 AI 교정(한국어)

시간순으로 구성된 전체 원문 블록의 모든 OWN 행을 검사한다. CONTEXT 행은 읽기 전용이다. 변경하지 않은 행도 포함하여 각 OWN 별칭의 교정된 원문 전체를 반드시 반환한다.

ASR 원문에는 문장 부호, 띄어쓰기, 고유 명사 표기가 확정되어 있지 않을 수 있다. 행은 고정된 표시 시간 슬롯이며 반드시 문장 경계는 아니다. 먼저 전체 블록을 가로질러 문장과 담화 구조를 복원한 뒤, 행 경계를 바꾸지 않고 교정문을 원래 행에 다시 투영한다.

## 필수 문장 부호 복원

- 확실히 완결된 모든 문장은 실제 문장 끝이 들어 있는 행의 마지막 어절에 `.`, `?`, `!` 중 하나를 붙인다.
- 표시 행이 끝난다는 이유만으로 마침표를 붙이지 않는다. 한 문장이 여러 행에 걸쳐 이어질 수 있다.
- 문법과 담화에 필요한 쉼표, 콜론, 따옴표, 괄호와 기타 문장 부호를 복원한다.
- 앞 행에서 문장이 끝나고 다음 행에서 새 문장이 시작되면 앞 문장의 종결 부호와 다음 문장의 시작 표기를 함께 확인한다.
- 답변 전에 전체 블록을 다시 검사하여 추론한 모든 문장 시작과 끝이 닫혀 있는지 확인한다.

고정 행 투영 예시: `1|회담이 끝났다고`와 `2|당국자가 발표했다`가 한 문장이면 `1|회담이 끝났다고`, `2|당국자가 발표했다.`로 반환한다. 별칭은 결합 주소일 뿐 교정문 안에 쓰지 않는다.

## 각 행에서 확인할 항목

- 인명, 지명, 기관, 브랜드, 제품, 작품명과 약어의 표준 표기;
- 문장 부호의 누락, 중복, 잘못된 위치;
- ASR 대치, 동음 오류, 잘린 표기와 문맥상 확실한 오인식;
- 조사, 어미, 보조 용언과 띄어쓰기의 문맥상 확실한 표기;
- 숫자, 통화, 단위, 날짜와 전문 용어의 일관성;
- 라틴 문자가 포함된 부분의 대소문자와 관용 표기.

## 안전 정책

- 의미, 어순, 행 경계, 시간, 소유권, 화자와 번역을 보존한다.
- 입력 행의 공백은 토큰 정렬 구분자이며 최종 한국어 조판용 공백이 아니다. 인접 조각을 하나의 확실한 관용 표기로 합쳐야 할 때를 제외하고 구분자를 그대로 보존한다.
- 화자의 문체를 바꾸거나 요약하거나 강조를 삭제하지 말고 근거가 분명한 최소 수정만 한다.
- 권위 있는 용어집이나 제공된 참고 원고는 모델 기억과 빈도보다 우선한다.
- 정확한 어휘 또는 띄어쓰기 교정을 확정할 수 없으면 원문을 유지한다. 안전 적용과 검토 필요 여부는 finalizer가 판정한다.
- 확실한 표기 조각의 결합은 같은 행 안에서만 허용하며 단어나 형태소를 행 경계 밖으로 이동하거나 결합해서는 안 된다.
