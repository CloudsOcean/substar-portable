# 中文源文边界规则

## 必须切开

- 已确认的说话人、轨道、标题、署名或独立话轮变化；
- 可独立成立的问答、感叹、反应语和互不依赖的功能内容；
- 完整句末、强停顿或明确话题重启；若受硬上限约束，应在上限前选择最自然的合法切点。

## 不可拆的最小结构

- 专名、机构名、节目名、成语、惯用语、术语、中英混排型号、网址、缩写或代码内部；
- 数字与量词/单位、金额、百分比、日期、时间和范围内部；
- “把/被/让/使/给”与其必要论元或核心谓语之间；
- 否定、程度、范围、情态或时体成分与其直接支配的谓语之间；
- 动词与不可缺少的短宾语、趋向补语、结果补语、可能补语之间；
- 短小偏正结构、数量结构、方位结构、连动、兼语、主谓谓语和紧密介宾结构内部；
- “的/地/得”与其直接依附成分之间；
- 引号、书名号、括号与其中很短且不可独立的内容之间。

功能词按实际句法归属放置，不按字面机械保护：

- 介词或话题标记可以随完整短语另起一个 Cue，例如“方案已经确定 / 关于预算的问题另行讨论”；但不得产生“关于 / 预算”或“在 / 北京”之类的断裂；
- “因为/如果/虽然/当/只要/除非”等通常跟随其引导的分句；“所以/但是/那么/而且”等若开启新的完整信息步骤，可以位于下一 Cue 开头，但不能单独成 Cue 或悬在上一 Cue 末尾；
- “的/地/得、了、着、过、吗、呢、吧”等助词不能成为下一 Cue 的孤立开头，也不能单独成 Cue；
- 真正位于完整话语末尾的语气词留在前一 Cue。

## 比较候选切点，选择自然边界

先理解完整表达，再结合语义、时间间隔和话轮选择边界。以下接缝都是候选，不必遇到就切；不要只等待句号，也不要把内容填到上限。依次考虑：

- 完整小句、主谓中心或话题—评述的完成处；
- 互相独立的并列分句、递进步骤和转折步骤之间；
- 在保持引导词与后续分句完整的前提下，切在原因、条件、让步、目的、时间或解释分句之前；
- 在保持介词与宾语完整的前提下，切在可独立附加的介宾短语之前；
- 列举项、补充说明、例证、插入语、话语重启和自然停顿之前；
- 长句必须从每个新 Cue 的起点重新寻找合法切点，必要时拆成三个或更多 Cue。

检查边界两侧：左侧应形成可理解的信息步骤，右侧应以可识别的短语或分句开头。避免以孤立的“的、地、得、把、被、在、对、向、从、和、但、而、就、都、也、又、才、还”收尾或开头；只有它在具体句法中确实属于该侧时才保留。自然性相当时再考虑长度平衡，不能为追求等长而破坏句法。

每个 Cue 都必须遵守请求中的 `hard_limit` 和起始词元对应的 `MAX_END`。硬上限是拒绝上限，不是推荐长度或填充目标，也不存在语义例外。若理想结构将超限，必须提前移动到损害最小的合法边界；不得超限、丢词、改写或重排原文。

## 输出前检查相邻字幕

- 先读完整词语和核心表达，再确定边界，不得切成“位 / 于”“不 / 过”“东 / 北”。
- 在上限允许、没有明确停顿或话轮变化时，保持动词与必要宾语、补语和后续动作完整，例如“进入房间内部”“需要更多的居民参与讨论”。不要让前条悬着谓语，后条只剩必要成分。
- 数量应和它所说明的动作或事物一起读懂；仅保证数字单位内部完整还不够。例如“生产燃气200万立方米”不宜切成“生产燃气 / 200万立方米”。
- 比较附近候选切点的语法完整性和实际时间间隔。不要跨过更自然的停顿后，又在连续发音的紧密结构中切开。时间间隔是结合语义判断的依据，不设统一的停顿阈值。
- 通读相邻两三条。如果存在更完整、且满足各条上限的切法，由你重新安排附近边界；可以提前切，也可以分成更多条，不追求最少条数或统一长度。
- 独立问答、感叹、反应语，以及有明确停顿支持的短句，可以很短。不要仅因字少或时长短而合并。
