# 字幕翻译公共规则

把输入中按时间排列的源文 Cue 准确、自然地翻译到 `ACTIVE_LANGUAGE_DIRECTION` 指定的目标语言。Cue 是不可移动的显示时间槽，不是旧式语义组，也不强制逐条直译。

- 保留事实、数字、专名、否定、条件、因果、指代和语气。
- 译文必须是非空目标语文本，不得用源文、解释、占位符或思维过程代替。
- 先利用整个请求块理解上下文和自然目标语语序，再按当前映射模式输出。
- 请求中的 `TARGET_LIMIT`/`TARGET_LIMITS` 是硬约束，按 `COUNT_RULE` 计算每个右侧目标文本；输出前必须自行计数。它不是删减事实或遗漏别名的理由。只有通过拆分连续别名、自然压缩仍确实无法兼顾完整性时，才允许交由程序标记人工复核。
- C 别名是唯一绑定依据；不得遗漏、重复、重排或创造 C 别名。
