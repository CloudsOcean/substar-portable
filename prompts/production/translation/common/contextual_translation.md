# 上下文重组翻译（many_to_many）
先连贯理解整块原文，再按目标语言组织内部连贯、自然收束的阅读片段。many_to_many 允许相邻 cue 重组，但重组是修复表达的工具，不是目标。原文换行不是译文的语义边界，不追求逐条对应，也不追求合并数量或最少行数。
在整体语义准确、单元内部连贯且符合长度预算的前提下，优先保留内容在原 cue 中，通过自然改写解决问题；这是一项整体理解后的分配偏好，不是逐 cue 独立翻译。只有原边界造成残缺、生硬、歧义、悬空，源语言语序难以自然转换，或原位改写仍无法满足长度预算时，才采用解决问题所需的最小幅度进行相邻重组。
不为追求独立完整句、整齐结构或更强表达扩大范围。能够在当前 cue 内自然表达并满足预算，就不搬移；需要轻微错位才能保持内部连贯时，也不要机械守住原边界。
单条写 1|译文；共享写 2-4|共同译文，程序复制到每个原 cue。内容移到相邻编号后，不要在原编号再次翻译；同一段原文的意思只表达一次，持续显示同一译文用范围表示。
必要重组时，允许相邻内容局部反序、前移或后移；显示编号始终递增，每个输入 cue 恰好覆盖一次。
每个输出是一段内部连贯、自然收束的阅读片段，可以是短语或分句，不必是独立完整句。省略上下文明确的主语可以；把否定、谓语或对象漏掉不可以。
开始推进新的动作、判断、转折或解释时，安排下一条字幕。同一主题或同一个主语不构成合并理由。通过逐步显示完整表达长句，不把整段压在一个范围上。
范围可覆盖两条、四条或更多条，但只覆盖解决表达问题所需的最小范围；范围共享不会增加 TARGET_LIMIT。不要把多步信息挤成一句，也不要为填满单条槽位制造“由”“向”“没有一个”之类悬空残片。
在准确、自然、内部连贯且符合长度预算的译法中，依次优先选择更像目标语言真实口语、信息移动更少、更贴近原讲话推进节奏的表达。不要仅为细微的措辞偏好扩大重组范围。
按目标语言习惯自然使用标点。不要删除标点、换成空格或串接分句来掩盖过度合并；判断依据是表达与信息推进。
输出前在内部核对：全部 cue 编号唯一覆盖；全部实义信息已表达；实体和否定准确；各单元长度合适。只返回译文行。

# 相邻归属与行内收束
以目标语言显示单元的内部连贯性决定相邻内容归属。原文 cue 边界不必成为译文边界；允许相邻 cue 之间轻微前移、后移或局部重排，使每次显示的译文能自然读下去，并在合适的位置收束。
不要求每条独立成句，但不要在紧密依赖的成分之间机械切断，例如介词与对象、否定与被否定的行为、修饰语与中心词、引述引导语与引述内容。不要把“他们说”“因为”“我们要”等引导语、关联词或未完成谓语单独悬挂在上一单元末尾。遇到这类断裂，先尝试原位自然改写；仍无法解决时再调整相邻内容分配，必要时使用范围共享。
轻微错位以修复局部表达为限。不跨明显停顿、说话人切换或话题边界搬移内容；不借连贯之名提前展示后续多个动作、判断或结论，也不大幅延后。能够自然收束且开始推进新信息时，进入下一显示单元。省略填充语后再决定相邻内容归属，不能为了填满槽位补写水词。
调整后按整个意义组检查信息是否完整，不要求每条译文与同编号原文逐项对应。内容移走后不得重复翻译，范围共享不增加长度预算。轻微错位只调整内容归属，不要求修改原 cue 时间槽。
例如连续输入（/ 表示换行）：49|you know, we've seen the Americans talk about sanctions, / 50|and they say, you know, / 51|we're going to cut off these Iranian banks.
不推荐：49|我们看到美国人在谈论制裁 / 50|他们说 / 51|我们要切断这些伊朗银行。
推荐：49-50|我们看到美国人在谈论制裁 / 51|他们说我们要切断这些伊朗银行。
这里省略两处 you know，把“他们说”轻微后移到引述内容所在单元，49–50 共享同一译文并自然收束；不是丢掉“他们说”。判断依据是单元内部是否连贯、信息是否仍随讲话推进，而不是是否守住原文分行。
