# 映射模式：多对多翻译（many_to_many）

输入 Cue 是不可移动的时间槽，不是必须逐句直译的语义边界。先理解整个连续请求块，再规划目标语言字幕在各时间槽上的自然显示。

- 每一行译文都应是自然、准确且语法身份明确的信息单元。
- 当一个不可自然再分的目标语片段确实需要跨越多个相邻时间槽持续显示时，用 `C001+C002` 这类连续别名组合，只写一份完整译文。
- 当目标语在边界处自然期待信息向前推进时，建立下一行，即使合并后的文本仍未超过 `hard_limit`。
- 不得把仅由源 Cue 边界造成的主语、谓语、宾语、介词或修饰语残片分别翻译。
- 可以按目标语自然语序重组相邻 Cue，但不得遗漏或增加信息，不得连接不连续的 C 别名。
- 允许 1:1、1:N、N:1 与 N:M 的语义重组；连续 C 组合负责表达跨槽持续显示。
- 每个 C 别名必须恰好出现一次，并严格保持输入顺序。
