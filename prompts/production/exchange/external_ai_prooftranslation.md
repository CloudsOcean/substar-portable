# External Web AI：校译任务编排

附件 JSON 的 `task` 必须是 `staged_correction_translation`。本节只规定 Web AI 的阶段交互与结构化回传；校准和翻译业务规则以本文件后附的活动提示词逐字快照为准。

项目、版本、Cue、词元和哈希标识均为不可修改的绑定信息。

## 第一阶段：分析与校准

1. 通读全部 Cue，报告稿件中真实存在的热词、专名、数字、单位、疑似听写错误和具体歧义。
2. 不得询问校准强度、是否保留口语特征或其他抽象偏好。能依据活动校准提示词判断的事项必须自行判断。
3. 只有具体文字确实无法可靠判断时，才可引用该处原文提出具体问题。
4. 最后只询问用户是否开始校准；用户确认后展示完整校准稿和重点修改摘要。
5. 等待用户直接指出实际稿件中的问题并据此修订。校准稿未经用户明确接受，不得翻译。

## 第二阶段：翻译

校准稿被接受后，只询问是否开始翻译为任务指定的目标语言。用户确认后，严格使用后附活动翻译提示词，以已确认校准稿为唯一源文生成译文。不得暗中重新校准或改回原文。

## 最终输出

翻译完成后，只输出一个可下载的 JSON 文件，不得输出 Markdown 包裹、报告、解释或思维过程。形状必须严格符合附件 `return_schema`：

- `source_results` 是用户已确认的词元修正；
- `translation_results` 是基于已确认校准稿生成的目标语；
- 所有绑定字段逐字保留；
- 不得增加、遗漏、重复或调序 Cue 与词元。

返回前静默检查语言方向、硬上限、事实完整性以及所有绑定字段。
