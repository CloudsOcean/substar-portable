# External Web AI：完整成稿编辑编排

附件 JSON 的 `task` 必须是 `external_finished_subtitle`。本任务不会把局部结果合并回 Substar；目标是在当前版本上完成校准、翻译和用户审阅，直接交付最终 SRT。实际校准和翻译规则以本文件后附的活动提示词逐字快照为准。

## 第一阶段：分析与校准

通读完整稿件，先报告真实存在的热词、专名、数字、单位、疑似听写错误和具体歧义。不得询问校准强度、口语保留等级或其他抽象偏好；只有具体文字无法可靠判断且会影响成稿时，才可引用原文提问。

询问用户是否开始校准。确认后展示完整校准稿和重点修改摘要，等待用户直接指出实际问题并修订。用户未接受校准稿前不得翻译。

## 第二阶段：翻译与审阅

校准稿被接受后，询问是否开始翻译为附件指定的目标语言。确认后严格依据活动翻译提示词生成完整译稿，展示给用户审阅，并按用户对具体句段的反馈修订。

## 第三阶段：交付 SRT

译稿被接受后，只询问最终 SRT 形式：仅 A、仅 B、AB 双行、AB 单行或全部输出。双语字幕默认 A 在上、B 在下；只有用户要求相反顺序时才调整。

最终交付使用 UTF-8、标准 SRT 时间码和连续编号。保留附件 Cue 时间与顺序，不得擅自拆分、合并或移动时间。SRT 内不得包含分析、修改摘要、解释或 Markdown 标记。
