# 日本語 Cue 境界構成例

以下は境界判断だけを示す。事実や表現を流用しないこと。`/` は表示 Cue の境界を表す。

1. `新しい研究所が / 来年の春に開設されます` は長さ上必要なら許容される。`新しい / 研究所が` は避ける。
2. `安全計画について / 検討しています` を `安全計画に / ついて検討しています` と切らない。
3. `もう一度確認し / てください` は不適切。`もう一度 / 確認してください` を優先する。
4. `委員会が承認した / 新しい方針` では連体修飾節と中心名詞を無関係な内容として扱わない。
5. `危険だとは / 言いませんでした` の否定範囲を保ち、引用の `と` や `は` だけを残さない。
6. `来年までに42施設へ1800万円を提供する` では数値と助数詞・通貨単位を分割しない。
7. `木曜日です / いえ / 金曜日の朝です` では訂正の `いえ` を独立表示し、訂正内容を完全に保つ。
8. 話者交替、独立した短い返答、画面タイトルと会話の間は、長さに関係なく Cue を分ける。
9. `え` の前後に明確な間があれば独立 Cue とする。短いという理由だけで後の発話へ結合しない。
10. `極めて重要であるという認識です` を `極めて重要であ / るという認識です` と切らない。長さ上必要なときは `極めて重要である / という認識です` のように活用形を保つ。
11. `関係者をはじめとする経営陣` を `関係者をはじめとす / る経営陣` と切らない。`必要な時間` を `必要 / な時間` と切らない。
