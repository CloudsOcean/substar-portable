# Contextual translation 일본어→한국어 대조 사례

1. `地元の技術者が提案した計画を / 委員会が / 承認しました` → `지역 기술자들이 제안한 방안을 / 위원회가 / 승인했습니다`. 비슷한 SOV 어순이라도 조사와 표시 경계를 기계적으로 일대일 대응하지 않는다.
2. `危険だとは言いませんでした / 再検査が必要だと述べただけです` → `위험하다고 말한 것은 아니고 / 추가 점검이 필요하다고만 밝혔습니다`. 부정과 한정 범위를 보존한다.
3. 일본어의 정중도와 한국어 높임 등급을 기계적으로 대응하거나 화자 관계를 새로 만들지 않는다.
