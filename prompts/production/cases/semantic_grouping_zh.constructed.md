# 中文 Cue 边界构造案例

以下案例只示范边界决策，不得套用事实或措辞。`/` 表示显示 Cue 边界。

1. **把字结构**：`我们把 / 新的安全方案 / 提交给了委员会` 不佳，因为“把”被悬空。推荐 `我们把新的安全方案 / 提交给了委员会`。
2. **被字结构**：`这项申请被 / 审查委员会驳回了` 不佳。推荐 `这项申请 / 被审查委员会驳回了`；不要拆开“被”与施事成分。
3. **动宾与补语**：`我们竭尽全力 / 按时完成 / 安全审查` 中，若当前硬上限允许且不存在更自然的合法边界，优先 `我们竭尽全力 / 按时完成安全审查`，不要产生只有“完成”的 Cue。
4. **长定语**：`委员会批准了 / 当地工程师提出的 / 新方案` 不佳，因为中心语“新方案”与短小“的”字结构分离。推荐 `委员会批准了 / 当地工程师提出的新方案`。
5. **否定范围**：`该机构并未表示 / 这座桥不安全 / 只是要求再次检查` 是连续断言；不得把第一条当成完整断言，也不要切成 `并未 / 表示`。
6. **关联结构**：`虽然成本有所上升 / 但是项目仍将继续` 可分两条显示，但必须保留在同一连续语义窗口；不得留下只有“虽然”或“但是”的 Cue。
7. **数字单位**：`未来三年将向42家地区诊所提供1800万美元` 不得切成 `42 / 家地区诊所`、`1800万 / 美元` 或拆开时间范围。
8. **条件与结果**：`如果河水再次上涨 / 北部公路将在午夜前关闭` 可在从句接缝显示切分，并须保留条件关系。
9. **连动结构**：`代表团前往日内瓦 / 参加下一轮谈判` 可以显示切分，但不能把“前往”单独成 Cue，也不能把两个动作误判为无关话题。
10. **自我纠正**：`会议定在周四 / 不对 / 是周五上午` 中，“不对”是独立修正话轮，应与前后陈述分开显示，同时让修正后的时间保持完整。
11. **独立短回答**：`你同意这个方案吗 / 同意 / 那我们继续` 中，“同意”是完整回答，应独立成 Cue，而不是为了减少 Cue 数量并入前一句。
12. **说话人与功能中心**：说话人变化、画面标题与对白必须形成 Cue 边界，即使合并后字符数更均衡。

案例展示的是推荐结果和典型错误，不要求输出分析过程。
