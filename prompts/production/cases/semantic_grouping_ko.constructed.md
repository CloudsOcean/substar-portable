# 한국어 Cue 경계 구성 사례

다음 사례는 경계 판단만 보여 준다. 사실이나 표현을 재사용하지 않는다. `/`는 표시 Cue 경계다.

1. `새 해안 연구소가 / 내년 봄에 운영을 시작합니다`는 길이상 필요하면 가능하다. `새 해안 / 연구소가`는 피한다.
2. `안전 계획에 / 대해서 검토하고 있습니다`보다 `안전 계획에 대해서 / 검토하고 있습니다`가 낫다.
3. `다시 확인해 / 주세요`처럼 보조 용언을 고립시키지 말고 `다시 / 확인해 주세요`를 우선한다.
4. `위원회가 승인한 / 새로운 방안`에서 관형절과 중심 명사를 서로 무관한 내용으로 다루지 않는다.
5. `위험하다고 / 말하지 않았습니다`의 부정 범위를 보존하고 인용 조사만 남기지 않는다.
6. `3년 동안 42개 병원에 1,800만 달러를 제공한다`에서 숫자와 단위·분류사를 분리하지 않는다.
7. `목요일입니다 / 아니요 / 금요일 아침입니다`에서는 정정 표현을 독립 표시하고 정정된 시간을 온전히 둔다.
8. 화자 변경, 독립된 짧은 대답, 화면 제목과 대사는 길이 균형보다 우선하여 Cue를 나눈다.
