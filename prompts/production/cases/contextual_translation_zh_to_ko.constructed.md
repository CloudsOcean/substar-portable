# Contextual translation 중국어→한국어 대조 사례

1. `委员会 / 批准了 / 工程师提出的方案`. Weak: `위원회는 / 승인했습니다 / 기술자들이 제안한 방안을`; Preferred: `위원회는 / 기술자들이 제안한 방안을 / 승인했습니다`. `N:M, full`.
2. `如果再次下雨 / 比赛 / 就会取消`. Preferred: `다시 비가 오면 / 경기는 / 취소됩니다`; 연결 어미나 종결 서술어를 고립시키지 않는다. `N:M, partial`.
3. `预计明年完工`은 주체가 명시되지 않았다면 `내년에 완공될 예정입니다`처럼 옮기고 회사나 기관을 임의로 추가하지 않는다.
